# Aplikasi Kalkulator Konsol

## Deskripsi Program
Aplikasi Kalkulator Konsol adalah program sederhana yang dibangun menggunakan bahasa Dart. Aplikasi ini menyediakan antarmuka berbasis teks untuk melakukan operasi matematika dasar.

## Fitur Utama
- **Operasi Penjumlahan**: Menjumlahkan dua bilangan
- **Operasi Pengurangan**: Mengurangi dua bilangan
- **Operasi Perkalian**: Mengalikan dua bilangan
- **Operasi Pembagian**: Membagi dua bilangan dengan validasi pembagi nol
- **Input Validasi**: Memvalidasi input pengguna untuk memastikan data yang dimasukkan adalah bilangan yang valid
- **Loop Berulang**: Pengguna dapat melakukan multiple perhitungan tanpa harus menjalankan ulang program

## Cara Menggunakan
1. Jalankan program dengan perintah `dart run`
2. Masukkan bilangan pertama
3. Masukkan bilangan kedua
4. Pilih operasi yang diinginkan (1-4)
5. Program akan menampilkan hasil perhitungan
6. Ikuti petunjuk untuk melakukan perhitungan berikutnya atau keluar dari program

## Struktur File
- `bin/main.dart`: File utama yang menjalankan aplikasi
- `lib/kalkulator.dart`: Kelas Kalkulator yang berisi logika operasi matematika
